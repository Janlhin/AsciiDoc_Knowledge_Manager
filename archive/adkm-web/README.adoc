`package.json` 自述：*ADKM · 浏览器界面的本地优先知识库（AsciiDoc + Markdown，Git 版本）*。

|===
|层 |实现

|===

== 三项对主项目有复用价值的设计

. *链接分类模型*（`shared/types.ts`）
`LinkKind = wikilink | markdown-link | xref | xref-short | link-macro | include`，配合 `LinkStatus = resolved | broken | unresolved`。
桌面版当前 `LinkRef` 只记录 `target / alias / from`，不区分链接种类。而"include 链断裂"与"正文交叉引用失效"是两类不同的问题——这是 *T-045（Docs-as-Code 工作流）与 T-046（文档规范体检）的地基*。
. *只读 Git 感知*（`server/git.ts`，77 行）
当前分支、ahead/behind、工作区脏文件清单。桌面版尚无任何 Git 感知能力，而对"文档工程"定位而言，Markdown/AsciiDoc + Git 是标准组合。
. *AsciiDoc 引用单独建模*（`server/parsers/asciidoc.ts`，229 行）
xref 短式、link-macro、include 分别处理，而非混同为「链接」。桌面版的统一引用模型可参考其分类边界。

`web/components/GraphView.tsx`（423 行）在此仅作对照：桌面版图谱已有约 1,969 行实现，更成熟，不建议反向移植。

== 已知不可移植点（归档时未修改）

下列路径写死了本机环境，*直接 clone 后无法运行*：

[options="header"]
|===
|文件 |问题
|`server/index.ts:10` |默认 vault 为 `<vault>`
|`server/parsers/asciidoc.ts:7` |Asciidoctor 以 `file:///<node 安装目录>/...` 引入
|`server/render.ts:7` |同上
|`start.ps1` |`-Vault` 默认值同为上述路径
|===

若要恢复运行，需要：① 把 vault 路径改为参数或环境变量；② 把 Asciidoctor 改为项目依赖（`@asciidoctor/core`）并动态导入；③ 补一份 README 级别的环境要求说明。
