= 多格式只读预览基线（T-054 / T-055 / D-022 / D-024）
:日期: 2026-11-15

== 结论

按用户决定「更多支持电子书格式并不再追求修改」「图片也预览」，本线**只扩展只读预览**：先做零依赖的 FictionBook 2 与漫画 ZIP，并把单张图片升级为共享图片阅读器；用户随后以「做 q005」放行新增依赖，再补 Kindle 家族（MOBI / KF8）。编辑能力**冻结在 Excel**，不再扩展，D-013 的「DOCX 真编辑 phase-2」撤销。

分两片：

. **T-054（零新增依赖）**：FB2 用平台 `DOMParser`，压缩包用既有 `jszip`；B 档格式完成「先搜寻后自研」评估但未引入任何新包。
. **T-055（Q-005 放行，仅 1 个依赖）**：引入 `@lingo-reader/mobi-parser@0.4.6`（MIT、196 KB、浏览器独立入口），落地 `.mobi/.azw/.prc` 与 `.azw3/.kf8` 只读预览，逐项登记见 `MANIFEST.adoc`、决策见 D-024。

== 架构与语义契约

* **注册表单点扩展**：`formatPreviewer(path)` 按小写扩展名查 `FORMAT_PREVIEWERS`。新增组件只需注册，无需改 `AttachmentView`（`formatPreview.ts:16-18`）。
* **复合后缀**：`fileExtension("book.fb2.zip")` 只返回 `zip`，因此先由 `ebookKindFromPath()` 按完整路径判定 `.fb2.zip` / `.fbz` / `.cbz`，再回落到单扩展名查表。
* **不可当只读电子书加入的格式**：`.txt` / `.html` / `.htm` / `.xml` 在 `EDITABLE_TEXT_EXTS` 中（`src/core/attachments.ts:253-272`），会路由进 CodeMirror 编辑器；要改成只读需动路由并承担回归风险，本片不动。
* **可取消加载契约**：`useFormatResource(path, loader)` 持有 loader 于 ref、effect 只依赖 `path`；loader 在每个 await 后检查 `isCancelled()`，返回 `dispose()` 释放 blob URL / 阅读器；取消后不 setState。新组件全部经此 hook，与 PR #27 为 EPUB 建立的契约一致；已验证的 `EpubPreview` 不重写。
* **数据安全边界**：所有附件仍只经 `vault.readBinary()` 读取，二进制永不进入 `documents.acquire` / CodeMirror 自动保存链路（`AttachmentView.tsx:1-8`）。`ImageReader` 不拥有也不创建 blob URL。
* **不可信内容**：FB2 解析为 `Fb2Block[]`，React 渲染文本节点，绝不 `innerHTML`；SVG 保持 `<img>` 上下文，不内联 DOM。FB2 内嵌 `<binary>` 解析为 `data:` URL。
* **排序**：CBZ 内图片按数值自然排序（`page2` 在 `page10` 之前），非图片条目忽略；所有 object URL 在切换/关闭时 `revokeObjectURL`。

== 检索评估（B 档）与 Q-005 放行结果

按规范检索顺序 0→3 执行：0/1（标准库 + 已有依赖）已满足 T-054 目标；2/3 对 MOBI/AZW3/DJVU/CBR/HEIC 等做了两轮检索（npm 包注册表 + GitHub + 包信息站点）。候选与排除理由逐项登记在 `MANIFEST.adoc`「格式扩展检索评估与放行记录」。要点：

. `foliate-js`（MIT）覆盖最广但作者明示 API 不稳定、维护放缓，替换现有 epub.js 链路风险过高。
. `@mdgate/mobi`（MIT）只输出 Markdown，丢图片/结构，作为「只读预览」会静默丢内容。
. `epubier` 需多个 peer 依赖与 worker 打包；`@lingo-reader/*` 其余子包与既有 epub.js / 自有 FB2 解析重复。
. `libarchive.js`（CBR）需 wasm worker；`libheif-js`（HEIC）为 **LGPL-3.0** 且 9 MB，需专门评估弱著佐权义务。
. DJVU / TIFF / JXL / PSD / RAW 未见许可清晰的成熟浏览器包。

**Q-005 结案（D-024）**：用户以「做 q005」放行新增运行期依赖后，**只引入 1 个**——`@lingo-reader/mobi-parser@0.4.6`（MIT、196 KB、`dist/index.browser.mjs` 独立入口、直接接受 `Uint8Array`）。选择理由：只要**解析器**不要阅读器 UI，与既有 `readBinary → 懒加载 → 渲染` 同形，无需 worker；自带 `destroy()` 释放其创建的 blob URL。其余候选**仍不引入**，再次放行需另开一片。

== Kindle 家族的格式路由细节（T-055）

* **扩展名路由**：`mobi.ts` 的 `kindleFormatOf()` 按完整路径判复合后缀——`.azw3` / `.kf8` 走 `initKf8File`，`.mobi` / `.azw` / `.prc` 走 `initMobiFile`；大小写不敏感。
* **不可信章节 HTML**：`sanitizeMobiHtml()` 用 `DOMParser` 解析后整棵剥离 `script` / `style` / 注释子树，只保留标题（`h1..h6`）、段落、图片，输出 `MobiBlock[]` 交 React 渲染文本节点；`<img>` 的 `src` 由解析器替换为自身 blob URL，渲染侧仍走 `<img>`，不内联 DOM。
* **按需加载**：打开时只取目录与章节清单，滚动到哪章解到哪章；不在首屏把整本转成 React 树，避免大部头卡死。
* **DRM / 损坏文件**：解析异常一律落到 `openFailed` 提示（不静默空白），不做任何解密尝试。

== 缺口（诚实记录）

. **编辑能力冻结**：保留 Excel 显式保存；若要求「连 Excel 也改成只读」，需单独一片移除 `XlsxPreview` 的保存与 `vault.modifyBinary` 路径，并同步 i18n / E2E / D-013 / T-018。
. **大 CBZ 全量入内存**：`readBinary` 一次读完整个压缩包；>100 MB 漫画需改为按需/流式解压。
. **FB2 覆盖有限**：只渲染 `title` / `subtitle` / `p` / `image` 与 section/epigraph/cite/poem 容器，表格、脚注、样式不还原；这是预览而非排版器。
. **无阅读偏好**：字号/主题/进度记忆按格式配置未做。
. **B 档尚未全做**：Kindle 家族已由 T-055 落地；CBR/CB7、HEIC/HEIF、DJVU/TIFF/JXL/PSD/RAW 仍未引入（wasm / LGPL / 无成熟包），需再次单独放行。
. **Kindle 无真实书籍真机验证**：仓库不打包第三方电子书二进制，E2E 用**合成无效文件**验证路由与错误反馈；真实解析链路由 Node 侧导入回归 + 组件级 mock 覆盖。DRM 文件必然失败并提示，不做解密。
. **真机验证范围**：E2E 用 1×1 PNG 与合成 FB2/CBZ/MOBI 夹具，未覆盖真实大部头书籍或加密/DRM 文件。
