= E2E 基线：WebView2 CDP 通道（T-004 / T-040）
:日期: 2026-11-15

== 结论

用 **WebView2 DevTools Protocol** 建立十一条高频路径的端到端回归，**零新增依赖**（只用 Node 内置模块 + 工具链已有的 `ws`）。
没有引入 Playwright / tauri-driver / msedgedriver：它们需要新依赖与 driver 版本配对，而 CDP 通道在本项目已被性能取数验证过。

* `npm run test:e2e` → 11/11 passed，退出码 0（T-045 第三片新增 `antora-version-switch`）
* `node tests/e2e/run.mjs --port=9222 --self-check` → 反转大纲用例的期望后该用例转红，自检退出码 0
* 未并入 `npm run verify`：E2E 需要运行中的 GUI，不能拖慢构建门禁（T-040 判据 ③）

== 运行方式

[source,bash]
----
# 1) 准备一个一次性 vault（夹具笔记 + docs/ 引用夹具 + catalog/ 两版本 Antora 组件
#    + sample.fb2 / sample.fb2.zip / sample.cbz / sample.png）
node tests/e2e/run.mjs --prepare /tmp/geode-e2e-vault

# 2) 用调试端口启动 release 版，指向该 vault
WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222 \
  ./src-tauri/target/release/geode.exe /tmp/geode-e2e-vault

# 3) 另一个终端跑用例
npm run test:e2e
----

端口绑定在 **IPv6 `::1`**（`localhost` 通、`127.0.0.1` 不通），`cdp.mjs` 已按此写死。
runner **不负责启动应用**：沙箱不允许脚本 spawn GUI 进程，而且测试框架也不该拥有应用生命周期。
环境变量覆盖：`E2E_PORT`、`GEODE_E2E_VAULT`、`GEODE_EXE`。

== 刻意不覆盖 / 观察到的现象

. **同文档锚点点击（T-033）未纳入自动用例。** Markdown 渲染器 `html: false` 且标题只带 `data-line`、不生成 `id`，因此 `[x](#h)` 没有可定位的目标；AsciiDoc `:toc:` 才是 T-033 的真实载体，但在一次性 vault 的 release 版里该预览渲染为空（见下条）。等载体稳定后补回。
. **一次性 vault 中 `.adoc` 阅读视图为空**（`preview` 的 `innerHTML` 为 0、无 `adoc-preview-view` class、大纲 0 项），但文件能被索引、搜索 snippet 有内容。尚不能判定是产品缺陷还是夹具/加载时序问题，已记入 T-049 待复核，本轮不擅自改产品代码。
. `spike/` 下 17 个 `.mjs` 探针只有 `cdp-check.mjs` 是 CDP 检查，其余硬编码本机 node 版本目录与 `file://` 路径、不可移植，**未收录**；本基线按可移植标准重写。
. 点击类交互分两种：绑在内部 `<button>` 的处理器（大纲行）必须用 `realClick()` 发真实鼠标事件；容器事件委托（预览内链接）用 DOM `click()` 冒泡即可。用错会静默「点不动」。
. `ai-proofread` 需要在会话中途改 `localStorage` 里的 provider 列表，而 LLM 的 Store 在模块初始化时读取它，因此该用例会 `Page.reload` 并重新连接 CDP；**用例结束会把 provider 快照还原并再次重载**，不让用户的真实配置指向已关闭的 mock 端口。它同时也是唯一一个自起本地 HTTP 服务的用例（`tests/e2e/mock-llm.mjs`，无需 Key、不出网）。
. 就绪判定（`app shell`）不能假设上一次运行结束时停在哪个标签：单例视图（文档体检 / 图谱）既没有 explorer 也没有 editor-pane。
  现按 `app-root` + 任一 `tab-bar-*` 判定，避免「上一轮以体检视图收尾 → 下一轮开跑即超时」这种自伤。
. `ai-proofread` 的第一条问题刻意落在**标题行**：阅读视图只对标题锚点加 `.preview-reveal-flash`，非标题目标走比例滚动、无闪烁类名；断言两种视图都能观察到的信号，才不会把「落在哪一行」误当成缺陷。
