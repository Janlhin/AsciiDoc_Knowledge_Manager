== 3. 必须现在决定的四个问题

=== P1 属性作用域：只认文档头，不引入工作区默认属性

*裁决*：索引期只使用该文档自身文档头定义的属性。未被引用的外部属性不注入。

*理由*：ADR-0002 已定「索引期不接受临时覆盖，保可重现」。若引入工作区默认属性集，同一文档在不同上下文下会解析出不同链接，图谱不可重现。

*代价*：跨文档共享的别名（如 `:spec:`）必须在每个引用方重复定义。这是可接受的——它把「忘记定义」变成显式的 `unresolved`，而不是静默解析到错误目标。

*待验证*：Blueprint 的 169 条属性驱动引用中，有多少所在文档未自行定义该别名。若比例高于 10%，需要重新评估此裁决。

=== P2 `include::`：L2 只登记边，不递归读取

*裁决*：`include::part.adoc[]` 在索引中产生一条指向 `part.adoc` 的边，但*不读取该文件内容、不把片段链接归入主文档*。

*理由*：递归 include 会把索引从「逐文件扫描」变成「图遍历」，需要环检测与深度上限；且片段归属是 ADR-0002 定义的语义问题，不是本层能顺带解决的。

*后果*：被 include 的文件若从未被单独打开，其内部链接不会出现在主文档节点下。这是*已知且有意*的简化，须在图谱 UI 与校验报告中体现，不能假装没有。

=== P3 索引与渲染是两条解析路径，结果可能不一致

*裁决*：索引走纯扫描（无 Asciidoctor 依赖），渲染按需懒加载 Asciidoctor.js。接受两者不一致。

*理由*：Asciidoctor.js 是 Node/浏览器全量解析器，体积与异步代价使其无法进入索引热路径（ADR-0001 已测）。而渲染必须有完整语义。

*约束*：所有面向用户的「引用」结论必须注明来源是「索引视图」。校验报告不得声称等同渲染结果。已知偏差类型：AsciiDoc 的条件包含、属性未定义时的默认值、`ifdef` 分支——扫描器一律按「文本原样」处理。

=== P4 链接类型区分：*不扩展 `LinkKind`，新增可选字段 `syntax`*

*裁决*：保持 `LinkRef.kind: "wikilink" | "markdown"` 不变，新增可选字段：

[source,ts]
----
syntax?: "xref" | "xref-short" | "link-macro" | "include";
----

*理由（关键）*：`kind` 是被严格比较消费的。现有 4 个文件按 `=== "markdown"` / `=== "wikilink"` 分支：

[source,text]
----
src/compat/obsidian/metadata.ts:660
src/core/linkRewrite.ts:181, 316
src/core/linkAtCursor.ts:12（自有局部类型）
----

若把 `kind` 扩成联合类型，这些 `===` 比较会*静默落到 else 分支*——最严重的后果是重命名文件时 `linkRewrite` 不再更新 adoc 里的 xref。这是重构类缺陷，不会报错，只会悄悄失效。

新增可选字段是加法，零影响；图谱着色、校验分类都可以用它。

*性能*：67 ms / 399 篇，远低于 §5 定的「130 篇 < 50 ms 的线」按比例折算值，也远快于 Asciidoctor 全量解析的 705 ms。索引走正则扫描这条路成立。

*P1 的待验证项有答案了*：220 条 adoc 引用中，属性占位符残留 *0* 条。也就是说所有 `xref:{alias}` 所在的文档都自行定义了该别名，「只认文档头」的裁决不会让任何一条引用失效，10% 的复核阈值未被触发。

*P2 在当前语料上是零影响*：真实存在的 `include::` 指令为 0（Blueprint 里两处 `include::` 都在行内代码里，是讨论该语法本身，不是指令）。

*md 回归*：用 `main` 的 worktree 作基线，同一批 md 文件跑两版索引，节点 / 边 / 反链 / 每条链接的解析结果*逐字段相同*。混合模式（md + adoc）下取出 md 子图再比一次，同样相同。

=== 实施中新增的一条规则

*无扩展名的链接优先匹配引用方自身的格式。* 原设计未提，但夹具暴露出问题：`Amb.md` 与 `Amb.adoc` 并存时，按字典序会落到 `.adoc`，于是"只是新增了一个 adoc 文件"就把既有 Markdown 链接改了指向。改为按引用方格式优先后，`Welcome.md` 的 `\[[Amb]]` 永远指向 `Amb.md`，`gate.adoc` 的 `\xref:Amb[]` 指向 `Amb.adoc`。显式写了后缀的链接仍以后缀为准。
